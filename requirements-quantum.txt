# NOTE: pyscf is deliberately NOT listed here any more.
#
# install.sh installs it LAST (step 15), because whether it should be the
# prebuilt wheel or a from-source build depends on whether this CPU has
# AVX-512 -- PySCF's shipped libcgto.so takes an AVX-512 codepath without
# runtime dispatch and dies with `Illegal instruction (core dumped)`
# without it. Listing pyscf here would also let a later pip step silently
# replace a correct source build with the broken wheel.
#
# If you are installing by hand rather than via install.sh:
#     grep -o 'avx512[a-z]*' /proc/cpuinfo | sort -u
#   nothing printed ->
#     pip install pyscf==2.11.0 --no-binary pyscf --force-reinstall --no-deps
#   otherwise ->
#     pip install "pyscf>=2.4"

# Qiskit ecosystem

# install.sh installs that repo with --no-deps precisely to avoid it; the
# ceiling here keeps a stray `pip install -U` from going to 3.x instead.
